Alteryx Use Case Presentation Script (Final with Q&A)

[Presentation]

Good afternoon.

Today, I would like to introduce an Alteryx use case that automates our file validation process, improving efficiency, accuracy, and risk control.

This process is designed to ensure data accuracy and consistency before delivering files to downstream teams.

Let me first walk you through the current manual process.

We start with data collection.
One person downloads raw files from the SAFE platform, and the second checker downloads the same files and manually renames them in English.

Next, we verify whether all file pairs exist, from Pair 1 to Pair 7, although some pairs may not be available depending on the day.

After that, the second checker manually compares each pair, checking key fields such as date, amount, and row count.

Finally, once everything is verified, the files are uploaded to a designated location.

However, this process is highly manual and repetitive.

It requires multiple validation steps, and there is always a risk of human error, such as missing file pairs, incorrect naming, or data mismatches.

It is also time-consuming and depends heavily on individual accuracy.
Especially when the data volume is large, it becomes difficult to perform accurate manual checks.

To address these issues, we implemented an automated workflow using Alteryx.

The data collection step remains the same, but instead of manual validation, we run the Alteryx workflow.

Alteryx identifies files created within the last 3 hours and performs three key checks:

- Pair existence between Korean and English-named files
- Format validation, such as column structure
- Content validation to ensure data consistency

It then generates an output file in a designated folder, highlighting any issues such as missing pairs or mismatches.
In addition, the output file serves as an audit trail, as the results are saved in a shared location for tracking and review.

As shown in the examples,

we can detect missing file pairs when certain pairs are not available on a given day.

We can also identify cases where only one side of the pair exists, for example when only the English file is present.

In addition, Alteryx can detect data mismatches between files.

Finally, it can flag format issues.
For example, if a new column is added on the platform, the file structure may change.

Since the downstream team relies on a fixed format to process the data, they may not recognize this change.

This validation helps detect such issues in advance and prevents downstream processing errors.

This automation delivers several key benefits.

It reduces approximately 26 hours of manual work annually.

It also significantly reduces operational risk by minimizing human error and improves accuracy through consistent validation.

In addition, it enables a more standardized and scalable process.

Going forward, we are planning to schedule the workflow so that it runs automatically at a specific time without manual intervention.

Overall, this use case demonstrates how automation can improve efficiency, accuracy, and risk management in our daily operations.

Thank you.


[Q&A]

Q1. Why is this level of validation necessary?
A1. Since the process is manual, there is a risk of incorrect naming, missing files, or data mismatches. Also, format changes may not be recognized. This validation helps detect these issues in advance and prevents downstream errors.

Q2. How often do these errors occur?
A2. They do not occur frequently, but even occasional errors can impact downstream processing. Therefore, consistent validation is important.

Q3. Why did you choose Alteryx?
A3. Alteryx allows efficient processing of multiple files, applying validation rules, and generating structured outputs. It also supports automation and scalability.

Q4. What happens after an issue is detected?
A4. The user reviews the output file, corrects the issue, and ensures only validated data is delivered.

Q5. Can this process be further improved?
A5. Yes, by scheduling the workflow to run automatically at specific times and further reducing manual intervention.
